# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to identify sales trends, customer behavior, product performance, and key business insights.

## Tools Used

- Excel
- SQL
- Power BI

## Analysis Performed

- Data cleaning and validation
- Sales and order analysis
- Customer analysis
- Product performance analysis
- Monthly sales trend analysis
- Category-wise analysis
- Key performance indicator (KPI) analysis

## Key Skills Demonstrated

- Excel data analysis
- SQL queries
- Data cleaning
- Data aggregation
- Joins
- Pivot Tables
- Power BI dashboard development
- Business insights

## Project Goal

To transform raw e-commerce data into meaningful insights that can support business decision-making.
